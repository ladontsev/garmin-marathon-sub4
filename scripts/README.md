# 📲 Инструкция по синхронизации тренировок с Garmin Connect Calendar

Скрипт **`scripts/sync_garmin_calendar.py`** автоматически считывает тренировочный план из [CALENDAR.md](../CALENDAR.md), формирует полноценные структурированные тренировки (*Structured Running Workouts*) и расставляет их по датам в вашем календаре **Garmin Connect**.

---

## 🎯 Что это дает на практике

Вместо того чтобы вручную забивать интервалы и настраивать пульсовые зоны в приложении Garmin, скрипт делает это в 1 клик:
1. **Автоматические подсказки на часах:** в день тренировки часы Garmin (Forerunner, Fenix, Epix, Enduro и др.) сами предлагают:  
   *«Запланирована тренировка: [Sub4] Пт - ЛОНГ (8.0k). Начать?»*
2. **Контроль зон в реальном времени:**
   * **Легкий бег и Лонги:** часы вибрируют и пищат, если ваш пульс выходит за рамки Зоны 2 (115–126 или 118–132 уд/мин), помогая избежать «серой зоны».
   * **Интервалы ПАНО и темповые отрезки:** часы ведут вас по отрезкам (например, 4 × 1 км в темпе 4:55/км), показывают шкалу «быстрее/медленнее», дают 2 минуты отдыха трусцой и отсчитывают повторы.
3. **Безопасность личных записей:** тренировки плана получают префикс `[Sub4]`. Любые ваши личные активности (бассейн, силовая в зале, йога) или памятные события календаря скрипт **никогда не удалит и не перезапишет**.

---

## ⚙️ Системные требования

* Python **3.10** или выше.
* Установленная библиотека `garminconnect` с поддержкой воркаутов:
  ```bash
  python -m pip install garminconnect pydantic
  ```

---

## 🚀 Сценарии запуска

Все команды выполняются из корневой папки проекта (`garmin-marathon-sub4`).

### 1. Безопасная симуляция (Dry Run)
Рекомендуется для первой проверки. Скрипт покажет, какие тренировки найдены в плане, без подключения к Garmin и без внесения изменений:
```bash
python scripts/sync_garmin_calendar.py --dry-run
```

---

### 2. Загрузка плана на ближайшие 4 недели (Рекомендуемый режим)
Оптимально вносить тренировки блоками по 3–4 недели. Это оставляет гибкость для адаптации темпа и объемов по самочувствию:
```bash
python scripts/sync_garmin_calendar.py --weeks 4
```
> [!NOTE] Авторизация при первом запуске
> При первом запуске скрипт запросит ваш **Email** и **пароль** от Garmin Connect (ввод пароля в терминале скрыт).  
> Скрипт выполнит вход через Garmin SSO и сохранит защищенные OAuth-токены сессии в папку `~/.config/garmin/tokens/`.  
> **При всех последующих запусках пароль больше запрашиваться не будет!**

---

### 3. Загрузка на другой период (8 недель или диапазон дат)
* **На 8 недель вперед (2 месяца):**
  ```bash
  python scripts/sync_garmin_calendar.py --weeks 8
  ```
* **На конкретные даты:**
  ```bash
  python scripts/sync_garmin_calendar.py --start-date 2026-11-10 --end-date 2026-12-31
  ```

---

### 4. Загрузка всего макроцикла (до сентября 2027 года)
Если вы хотите залить сразу все 140 запланированных тренировок на весь сезон:
```bash
python scripts/sync_garmin_calendar.py --all
```

---

### 5. Очистка календаря Garmin от тренировок плана
Если вы решили кардинально переписать расписание и хотите снять все тренировки плана с календаря часов за определенный период (ваши личные записи, напоминания и тренировки вне плана останутся нетронутыми):
```bash
python scripts/sync_garmin_calendar.py --clear --weeks 4
```
*(После очистки можно сразу запустить заливку нового плана).*

---

## 🔄 Как работает обновление при изменении плана

Если вы изменили дни тренировок, увеличили километраж лонга или скорректировали темп в [CALENDAR.md](../CALENDAR.md), просто запустите скрипт заново:
```bash
python scripts/sync_garmin_calendar.py --weeks 4
```

Скрипт работает **идемпотентно**:
1. Сравнивает то, что написано в `CALENDAR.md`, с тем, что уже висит в Garmin Connect на эти даты.
2. Если тренировка совпадает — оставляет без изменений (не плодит дубликаты).
3. Если параметры дня изменились — аккуратно снимает устаревшую тренировку с календаря (`unschedule_workout`) и назначает свежую.
4. Прошлые завершенные дни (`date < today`) скрипт **никогда не трогает**, чтобы не затереть историю тренировок и треки забегов.

## 🛡 Безопасность учетных данных

* Ваши учетные данные **никогда не попадают в Git**: папка токенов `~/.config/garmin/tokens/` расположена вне репозитория в вашем пользовательском профиле.
* В репозитории в `.gitignore` надежно заблокированы любые файлы ключей, `.env` и дампы сессий.
* При желании отозвать доступ достаточно удалить папку:
  * **Windows:** `Remove-Item -Recurse -Force ~/.config/garmin/tokens`
  * **Linux / macOS:** `rm -rf ~/.config/garmin/tokens`

## ❓ Часто задаваемые вопросы (FAQ)

### 1. Что делать, если включена двухфакторная аутентификация (MFA / 2FA)?
Библиотека `garminconnect` поддерживает ввод MFA-кода: при входе в терминале появится запрос: *«Enter MFA code:»* — введите код из SMS или приложения-аутентификатора.

### 2. Как удалить тренировку из библиотеки шаблонов Garmin?
Скрипт снимает тренировку с даты календаря (*unschedule*). Если вы хотите полностью удалить шаблон воркаута из списка «Мои тренировки», это можно сделать в один клик в приложении Garmin Connect: *Тренировки и планирование → Тренировки → Удалить*.

### 3. Тренировка появилась в календаре приложения, но её нет на часах?
Убедитесь, что часы подключены по Bluetooth к телефону и выполнена синхронизация (круглая стрелка в правом верхнем углу Garmin Connect). Также можно синхронизировать часы через Wi-Fi прямо из меню настроек часов.
